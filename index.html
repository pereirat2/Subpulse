// Impact

An attacker controlling the target endpoint can serve arbitrary HTML, JavaScript, and TLS-trusted content under this organisation's domain. This enables:

  • Phishing campaigns using legitimate, trusted hostnames
  • Cookie theft / session hijack via shared-parent cookies
  • OAuth / SSO callback hijacking and SAML relay abuse
  • CSP / CORS bypass against sibling first-party origins
  • Brand reputation damage and SEO poisoning

// Remediation

Choose one of the following — the faster, the better:

  • Remove the dangling DNS record from the authoritative zone
  • Re-claim the resource on the upstream provider
  • Repoint the record to an asset you actively control
  • Adopt a DNS hygiene policy: periodic orphan-CNAME sweeps
  • Monitor the zone continuously for newly-dangling records
